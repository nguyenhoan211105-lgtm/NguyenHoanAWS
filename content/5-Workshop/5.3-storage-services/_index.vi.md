# 5.3. Triển khai các dịch vụ lưu trữ

Chương này khởi tạo hai tầng lưu trữ của hệ thống: **Amazon S3** để lưu trữ file thực tế, và **Amazon RDS (MySQL)** để lưu trữ metadata có cấu trúc.
