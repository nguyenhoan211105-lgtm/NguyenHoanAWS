# 5.2.3. Creating and Configuring the Internet Gateway

1. In the VPC console, go to **Internet Gateways** > **Create internet gateway**.
2. Name it `my-igw-01` and click **Create internet gateway**.
3. Select the newly created gateway, go to **Actions** > **Attach to VPC**, and select `my-vpc-01`.
