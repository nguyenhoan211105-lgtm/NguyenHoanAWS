# 5.2.3. Tạo và cấu hình Internet Gateway

1. Trong VPC console, vào **Internet Gateways** > **Create internet gateway**.
2. Đặt tên `my-igw-01` và nhấn **Create internet gateway**.
3. Chọn gateway vừa tạo, vào **Actions** > **Attach to VPC**, chọn `my-vpc-01`.
