# 5.2. VPC Network Design & Deployment

This chapter provisions a highly-available VPC spanning **two Availability Zones**, with public subnets (ALB, NAT Gateway) and private subnets (EC2, RDS) — following AWS best practices for a production-style 2-tier application.
