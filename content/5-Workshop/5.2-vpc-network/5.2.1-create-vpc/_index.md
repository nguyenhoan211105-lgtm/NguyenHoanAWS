# 5.2.1. Creating the VPC

1. In the AWS Console search bar, enter **VPC** and open the **VPC** service.
   ![vpc](/images/5-Workshop/5.2-vpc-network/vpc.png)
2. Select **Create VPC**, then choose **VPC only**.
   ![vpc_create](/images/5-Workshop/5.2-vpc-network/vpc_create.png)
3. Configure the VPC:
   * **Name tag**: `my-vpc-01`
   * **IPv4 CIDR block**: `10.0.0.0/16`
   * **Tenancy**: Default
   * **No IPv6 CIDR block**
4. Click **Create VPC**.
