# 5.2.1. Khởi tạo VPC

1. Trong thanh tìm kiếm AWS Console, gõ **VPC** và mở dịch vụ **VPC**.
   ![vpc](/images/5-Workshop/5.2-vpc-network/vpc.png)
2. Chọn **Create VPC** rồi chọn **VPC only**.
   ![vpc_create](/images/5-Workshop/5.2-vpc-network/vpc_create.png)
3. Cấu hình VPC:
   * **Name tag**: `my-vpc-01`
   * **IPv4 CIDR block**: `10.0.0.0/16`
   * **Tenancy**: Default
   * **No IPv6 CIDR block**
4. Nhấn **Create VPC**.
